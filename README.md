# Kana Kitchen

Browser-based **Japanese-style keyword converter**. Type English text and get a playful stylized output in real time.

## Features

- Live conversion as you type
- Simple, dependency-free UI (HTML + vanilla JS)
- Easy-to-edit character map in `script.js`

## Tech

Vanilla JavaScript · HTML · CSS

## Run

```bash
git clone https://github.com/bugship/kana-kitchen.git
cd kana-kitchen
open index.html   # or double-click / serve with any static server
```
